# Brainstorming

## Was wir über Emmi wissen
- 2. Klasse, liest gut, darf auch anspruchsvoller sein
- Hobbys: Ballett, Karate, Singen, Gartenarbeit, Klettern
- Liebt Basteln, Flechten, Häkeln
- Lernziele: Portugiesisch, Englisch, Grundschulstoff 2. Klasse
- Gerät: Android-Tablet

## Grundidee: Emmis Tierwelt (Idee 1)
Emmi hat einen eigenen Garten mit einem kleinen Hof. Aufgaben in Mini-Spielen bringen
**Sterne** (Währung), mit denen sie Pflanzen, Tiere, Gehege und Deko kauft. Tiere und
Pflanzen brauchen Pflege, die Welt wächst sichtbar mit ihrem Lernfortschritt.

### Orte = Mini-Spiele (an ihre Hobbys angelehnt)
| Ort | Spiel | Lerninhalt |
|-----|-------|------------|
| 🌱 Gemüsebeet | Säen, gießen, ernten – jede Pflanze braucht eine gelöste Aufgabe | Plus/Minus bis 100, Zehnerübergang |
| 🥋 Karate-Dojo | Bretter zerschlagen: schnell die richtige Antwort tippen | Einmaleins (Tempo, Kopfrechnen) |
| 🧗 Kletterwand | Griff für Griff nach oben, jeder Griff ein Wort | Rechtschreibung, Wortarten (Nomen/Verb/Adjektiv) |
| 🩰 Ballettbühne | Tanzschritte merken und nachtippen | Merkfähigkeit, Muster, Uhrzeit-Choreo |
| 🎤 Singbühne / Radio | Wörter hören → richtiges Bild wählen | Englisch & Portugiesisch Vokabeln (vorgelesen) |
| 🧶 Bastelstube | Armbänder flechten, Muster häkeln, symmetrische Bilder | Muster fortsetzen, Symmetrie, Formen, Geld (Material kaufen) |
| 🐔 Tierhof | Tiere füttern: Tiere „sprechen" auf EN/PT | Sprachen im Alltag, Leseverständnis |
| 🏪 Hofladen | Ernte verkaufen, Wechselgeld geben | Geld (Euro/Cent), Sachaufgaben |

### Belohnungen & Motivation
- Sterne → neue Tiere, Pflanzen, Deko, Kostüme (Ballett-Tutu, Karate-Gürtel)
- **Karate-Gürtelsystem** als Level-Anzeige (weiß → gelb → orange → … → schwarz)
- Tagesaufgabe („Heute haben die Hühner Hunger") statt Druck
- Sticker-Album / Bastel-Sammlung

### Sprachen
- Vorlesen per Sprachausgabe des Tablets (Deutsch, Englisch, Portugiesisch)
- Jedes Tier/jede Pflanze hat Namen in DE / EN / PT
- Spracheinstellung: z. B. „Tierhof spricht heute Portugiesisch"

### Technik
- PWA (HTML/CSS/JS), offline, auf Android-Startbildschirm installierbar
- Fortschritt lokal auf dem Gerät gespeichert
- Eltern-Bereich (Rechenaufgabe als Sperre): Fortschritt, Schwierigkeit, Zeitlimit

## Entscheidungen

- Stil: niedlich-bunt gezeichnet
- Erster Prototyp: Garten + Karate-Dojo + Hofladen
