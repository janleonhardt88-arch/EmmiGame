# Brainstorming

## Offene Fragen
- Wie alt ist Emmi? Kann sie schon lesen?
- Welches Tablet (iPad / Android)?
- Was liebt sie gerade? (Tiere, Einhörner, Dinos, Weltraum, Prinzessinnen, Feuerwehr …)
- Was soll sie lernen? (Zahlen, Buchstaben, Uhr, Farben/Formen, Englisch …)
- Wie lange soll eine Runde dauern?

## Ideen

1. **Emmis Tierwelt / Bauernhof** – Aufgaben lösen → Sterne → Futter/Gehege kaufen, eigene Tierwelt wächst.
2. **Buchstaben-Garten** – Buchstaben antippen/nachspuren, daraus wachsen Blumen; später Silben & Wörter.
3. **Zahlen-Zug** – Waggons mit der richtigen Menge beladen, zählen, später plus/minus.
4. **Emmis Abenteuerbuch** – kleine Geschichte, an Weggabelungen kurze Lernaufgaben.
5. **Mini-Spiele-Sammlung** – Memory, Formen sortieren, Farben mischen, Uhr lernen, Sticker-Album als Belohnung.

## Prinzipien
- Große Buttons, wenig Text, viel Ton (vorgelesene Anweisungen)
- Fehler sind nicht schlimm – kein „Game Over", sanftes Nochmal-Versuchen
- Belohnungen sammeln (Sticker, Sterne, Freischaltungen)
- Schwierigkeit passt sich langsam an
- Optional: Eltern-Bereich (Fortschritt, Zeitlimit)
- Persönlich: Emmis Name, eigener Avatar, vielleicht eure Stimmen
