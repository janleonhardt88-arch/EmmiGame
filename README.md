# EmmiGame 🎈

Ein kleines Lern- und Spaßspiel für Emmi – gebaut für ihr Tablet.

**Status:** Brainstorming-Phase. Ideen und offene Fragen stehen in [`docs/BRAINSTORMING.md`](docs/BRAINSTORMING.md).

## Geplante Technik (Vorschlag)

- **Web-App (PWA)** mit HTML/CSS/JavaScript
- Läuft auf iPad *und* Android-Tablet im Browser
- Lässt sich per „Zum Home-Bildschirm hinzufügen" wie eine echte App installieren
- Funktioniert offline, kein App Store, keine Werbung, kein Tracking
- Hosting kostenlos über GitHub Pages
